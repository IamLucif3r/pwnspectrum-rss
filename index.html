These flaws are stack-based buffer overflows that can allow unauthenticated actors to terminate the Traffic Management Microkernel (TMM) and potentially execute code remotely.     Why it matters. Exploitation can lead to denial-of-service or remote code execution on vulnerable systems. F5 noted these are data plane issues only, with no control plane exposure.

    Do this today Install the out-of-band hotfixes released by F5.

    A heap-based buffer overflow vulnerability, tracked as CVE-2026-132825, exists in Ruby's string case conversion. This flaw can cause the program to write past the output buffer when changing case in certain single-byte encodings. The vulnerability impacts character case-conversion operations in applications using Rails or classic-style Sinatra.

    Why it matters. Unauthenticated attackers could trigger this defect, potentially leading to remote code execution or denial-of-service. Applications that change the case of external text in a single-byte encoding are at risk.

    Do this today Update Ruby to version 4.0.10, 3.4.13, or 3.3.14.
