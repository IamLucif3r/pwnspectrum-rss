  • NGINX: HTTP/2 Integer Underflow Allows Unauthenticated RCE High·PoC public·CVSS 8.1·5 outlets·Rapid7Day 2NewRead An integer underflow in NGINX's HTTP/2 handling permits unauthenticated remote code execution.

    CVE-2026-123007 is an integer underflow vulnerability in NGINX's HTTP/2 implementation. An unauthenticated client can exploit this by manipulating flow-control credit, causing memory corruption. This corruption can lead to code execution with the NGINX worker process's permissions.

    Why it matters. Exploitation allows remote attackers to execute arbitrary code on servers running vulnerable NGINX instances with HTTP/2 enabled. This risks compromising websites and APIs served by the affected software.

    Do this today Upgrade nginx to version 1.31.9 or 1.30.7 or later.
