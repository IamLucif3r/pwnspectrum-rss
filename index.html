    CVE-2026-123007 is an integer underflow vulnerability in NGINX's HTTP/2 support. An unauthenticated remote client can exploit this by manipulating HTTP/2 flow-control credit. This manipulation causes memory corruption, potentially allowing code execution with the NGINX worker process's permissions.

    Why it matters. Exploitation allows unauthorized remote code execution against services using NGINX with HTTP/2 enabled. This compromises the underlying server and data handled by the service.

    Do this today Upgrade nginx to version 1.31.9 or 1.30.7.
