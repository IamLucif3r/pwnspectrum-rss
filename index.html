  • Microsoft agent-framework Compromised: Credential Stealer Targets Azure and CI Pipelines High·Wiz ResearchNewRead Malicious versions of the Microsoft PyPI package agent-framework were published, deploying a credential stealer upon Python interpreter startup.

    Versions 1.26.1 and 1.26.2 of the agent-framework package were published to PyPI containing credential stealers. These versions drop .pth files that execute the stealer whenever Python starts in the environment. The stealer collects environment variables, credential files, and Azure/OIDC tokens before sending them to webhook.site.

    Why it matters. Compromise allows theft of credentials for Azure, AWS, GitHub, and other services, potentially leading to unauthorized access. Stolen managed-identity and OIDC-exchanged tokens are valid for up to 24 hours.

    Do this today Search lockfiles, CI logs, virtualenvs, and container images for agent-framework 1.26.1 or 1.26.2 and pin dependencies to 1.26.0.
