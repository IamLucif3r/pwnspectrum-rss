  • GL.iNet Cloud Flaw Exploited to Infect Routers and KVM Devices Critical·Exploited·GL.iNet via BleepingComputerNewRead Malware was installed on GL.iNet devices via an exploited vulnerability in the cloud remote management service.

    Unauthorized parties exploited a vulnerability in GL.iNet's cloud remote management services to install custom malware on routers and KVM devices. This resulted in backdoors and reverse shells providing remote access to infected equipment.

    Why it matters. Compromised devices may have had access to controlled computers via KVM, requiring analysis of those connected systems for potential compromise.

    Do this today Install the latest security firmware for specific models; for KVM devices, use version 1.10.3 or later for RM10, RM1, RM1V2, RM1PE, and RM4PE.
