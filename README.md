# PwnSpectrum

The published site for [PwnSpectrum](https://feed.anmolsinghyadav.com), a daily cybersecurity brief.

Everything here is generated by [SARJAN](https://github.com/IamLucif3r/SARJAN) — please do not edit files by hand.

- `/` latest brief, `/YYYY/MM/DD/` permanent briefs, `/archive/` all briefs
- `archive/*.html` are v1-format briefs kept so old links keep working
