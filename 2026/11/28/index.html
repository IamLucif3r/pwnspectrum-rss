  • Linux NFS Server Flaw (CVE-2026-99362) Allows Remote Root Access High·CVSS 9.8·OpenSec via BleepingComputerNewRead A critical, unauthenticated flaw in the Linux NFS server allows remote attackers to gain root privileges.

    CVE-2026-99362 is a critical vulnerability in the Linux kernel's NFS server, stemming from a heap buffer overflow. Successful exploitation allows remote attackers to corrupt kernel memory and gain root access.

    Why it matters. Exposure of NFS services on port 2049 allows unauthenticated remote takeover of vulnerable Linux servers. This flaw has been present since 2014.

    Do this today Apply the latest kernel security updates from the Linux distribution vendor and reboot the system.

    Affected
    Linux kernel versions older than 6.12.117, 6.18.61, 7.3.2, or 7.4-rc1
