  • Apple Details Secure Exclaves for Ambient Sensor Data Isolation Medium·Apple via SecurityWeekNewRead Apple detailed Secure Exclaves, a hardware architecture isolating ambient sensor data from the main OS.

    Apple published details on Secure Exclaves, a hardware-backed security architecture for ambient sensing on devices like HomeView and new iPhones. This design separates camera and microphone processing from the main operating system, preventing access even if the kernel is compromised.

    Why it matters. This architecture limits data exposure by ensuring the main OS cannot access or alter data processed within an exclave. Only specific metadata is shared with the main OS during background sensing.

  • NoisyTCP Vulnerability in Linux Kernel Causes Denial of Service Medium·BleepingComputerNewRead A Linux kernel flaw allows unauthenticated remote attackers to cause a Denial of Service via crafted TCP packets.

    The NoisyTCP vulnerability, tracked as CVE-2026-99288, is a pre-authenticated remote corruption flaw in the Linux kernel's TCP networking subsystem. It stems from a NULL pointer dereference weakness triggered by exploiting the timing between SYN cookie handling and socket hashing.

    Why it matters. Exploitation results in a kernel panic and host shutdown, causing a Denial of Service. The vulnerability affects systems running Nginx, Apache, and SSH servers with default configurations.

    Do this today Disable SYN cookies and serialize to a single RX queue if immediate patching is not possible.

    Affected
    Almost all Linux distributions
