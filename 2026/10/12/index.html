  • AWS AgentCore Vulnerability via Metadata and Permissions Medium·The RegisterNewRead AgentCore can leak temporary AWS credentials via IMDSv1, allowing lateral movement and resource compromise.

    AgentCore utilized IMDSv1, allowing an attacker to prompt the agent to request metadata containing temporary AWS credentials. Weak VM isolation and overpermissioned default roles enabled the attacker to enumerate, pull images, and interact with other agents in the same AWS region.

    Why it matters. Compromise of credentials allows an attacker to launch new agents, read user sessions, and alter agent behavior by writing to agent memories.
