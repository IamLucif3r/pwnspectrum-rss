  • FreeBSD Kernel: kqueue Use-After-Free Local Privilege Escalation High·CVSS 7.8·Zero Day InitiativeNewRead Local attackers can escalate privileges on FreeBSD Kernel via kqueue Use-After-Free flaws.

    Two vulnerabilities were identified in the FreeBSD Kernel affecting the kqueue function. The flaws stem from improper locking during object operations within the FIOSSHMLPGCNF handler. Exploitation allows local attackers to escalate privileges and execute arbitrary code in kernel context.

    Why it matters. Successful exploitation grants local attackers elevated privileges on the system. Both vulnerabilities require the attacker to first execute low-privileged code on the target machine.

    Do this today Apply the update detailed in FreeBSD-SA-26:63.posixshm.asc.
