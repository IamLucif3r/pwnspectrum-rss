  • Brotli Decoder Flaw (CVE-2026-111497) Enables RCE Across Multiple Technologies Critical·PoC public·CVSS 9.2·Wiz ResearchDay 3NewRead A memory-corruption flaw in the Brotli decoder allows unauthenticated remote code execution via crafted compressed data.

    CVE-2026-111497 is an out-of-bounds write vulnerability in the Brotli decompression library. Exploitation occurs when an application processes specially crafted Brotli-compressed data. This flaw affects components like Node.js, Bun, and Envoy Proxy.

    Why it matters. Successful exploitation can lead to memory corruption, disclosure of sensitive information, application crashes, or remote code execution with the privileges of the affected process. Cloud environments are particularly exposed due to widespread use of Brotli-enabled components.

    Do this today Upgrade affected Brotli libraries, Node.js runtimes, Bun, Envoy Proxy, and Istio deployments to patched versions.

    Affected
    Node.js, Bun, Envoy Proxy, Python Brotli packages, and any application using the Brotli C decoder
